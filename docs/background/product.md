# 产品定位

## 一句话定义

Softplan 是一个基于大模型的**软件项目规模与成本估算分析平台**。从项目文档中自动提取需求信息，进行功能点分析与成本估算，允许用户对中间结果进行审阅、修正和重新估算。

## 定位约束（AI 写代码时必须遵守）

**是什么**：
- 分析平台，关注"分析过程 + 中间结果 + 最终估算"的完整链路
- 开源工具，面向研究者和项目估算人员
- 强调高可解释性：不能只给结果，必须展示中间分析依据

**不是什么**：
- 不是 SaaS 系统，当前无登录/注册/支付/多租户
- 不是黑盒估算工具
- 不是知识库或 RAG 系统

## MVP 范围

当前已实现的核心链路：
- 项目创建与管理
- PDF 文档上传与解析（调用外部 file-convert-service）
- 文档结构化（document_structuring agent）
- 文本摘要（text_summary agent）
- LLM 配置管理

**尚未实现**（不要在没有讨论的情况下擅自实现）：
- IFPUG 功能点分析
- 成本估算模块
- 报告生成
- 人工修正中间结果的 UI

## 项目状态枚举（代码实际值）

`project.status` 的取值：`draft` | `analyzing` | `completed` | `archived`

注意：PRD 中描述的 7 个状态是规划稿，代码实际只有以上 4 个。
